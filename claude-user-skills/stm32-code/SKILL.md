# STM32代码实现Skill

## 1. 输入规范

当前工作目录为项目根目录，项目名称`<project-name>`取当前目录名称。

`<task-id>`为Skill调用时指定的编程任务编号，例如`T01`、`T02`。本Skill将`<task-id>`对应的编程任务称为“当前编程任务”。

读取编程任务清单`docs/tasks/task_list.md`。

根据当前编程任务规定的涉及文件和主要修改位置，读取需要修改的源码文件。

## 2. 输出规范

按照当前编程任务规定的任务目标、涉及文件、主要修改位置和实施要点修改代码。

代码修改完成后，输出当前编程任务的修改摘要和验证要求。

## 3. 执行步骤

### 3.1 读取当前编程任务

1. 读取编程任务清单，定位`2. 编程任务详细说明`中的当前编程任务。
2. 读取当前编程任务的任务目标、涉及文件、主要修改位置、实施要点和验证要求。
3. 根据涉及文件和主要修改位置读取需要修改的源码文件。
4. 如果编程任务清单或相关源码文件读取失败，则进入异常出口。

### 3.2 检查任务实施条件

1. 检查当前编程任务规定的涉及文件和主要修改位置是否与实际源码一致。
2. 如果规定的文件或主要修改位置不存在，或与实际源码不一致，则进入异常出口。

### 3.3 实施代码修改

1. 严格按照当前编程任务规定的任务目标、涉及文件、主要修改位置和实施要点实施代码修改。
2. 调用本Skill后直接实施代码修改，不再对写入操作进行业务确认。

## 4. 边界约束

1. 不得修改编程任务清单，不得重新规划、扩展、删减或改变当前编程任务要求。
2. 不得在当前编程任务规定的涉及文件和主要修改位置之外修改代码。
3. 本Skill只进行代码修改，不进行代码验证，不得自动执行构建、编译、工程生成或烧录。

## 5. 出口规范

### 5.1 正常出口

当前编程任务规定的代码修改完成后进入正常出口。

如果进入正常出口，输出当前编程任务摘要，并提示开发者按照编程任务清单中的验证要求进行验证。

最后调用`stm32-log` Skill，并结束本Skill。

### 5.2 异常出口

不满足正常出口条件时进入异常出口。

如果进入异常出口，输出未完成原因和当前执行状态。

最后调用`stm32-log` Skill，并结束本Skill。
